REPORTE DE DISOLUCIÓN - BITÁCORA (ARCHIVOS LISTOS PARA COPIAR)
================================================================

Este paquete está preparado contra la rama `desarrollo` del proyecto
AdministradorRecetasApizaco. NO requiere ejecutar Python, integradores ni
scripts de instalación. NO modifica GitHub y NO modifica el SCADA.

CÓMO USAR
1. Haz un respaldo de las versiones actuales de tu frontend y backend.
2. Extrae el ZIP.
3. Arrastra las carpetas "AdministradorRecetasPrebatchBackend" y
   "AdministradorRecetasPrebatchFrontend" a la carpeta que contiene tus
   dos proyectos, y acepta combinar carpetas y reemplazar archivos.
4. Compila ambos proyectos y prueba el proceso 177.
   Backend: mvn -DskipTests clean package
   Frontend: npx ng build

  la sección BITÁCORA DE PROCESAMIENTO al mismo PDF.
- Se incluye resumen de componentes por posición con columnas de duración
  y ciclos, aún como pendientes de datos reales.
- NO se consulta ni se agrega la sección de códigos de barras.
- El archivo existente reporte-pdf.service.ts NO se sustituye; se reutiliza
  la composición actual del PDF mediante un adaptador. Cuando se refactorice
  el servicio original, conviene exponer formalmente un método público para
  construir el documento en lugar del acceso de compatibilidad temporal.
- NO se alteran las funciones ni componentes ajenos al reporte.

PROCESO 177

- Los pasos 2-5, unidad, ciclos, duración, agua real y meta real NO constan
  en los datos proporcionados. Se marcan PENDIENTE SCADA.
- Los valores de agua en step=1 no se usan como confirmación de dosificación.
